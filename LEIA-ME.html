Geoportal de Ariquemes

A aplicação utiliza os três arquivos GeoJSON fornecidos pela professora. Nenhuma feição foi removida ou recortada. O fundo inicial é OpenStreetMap; também estão disponíveis Esri World Imagery e OpenTopoMap. Os fundos exigem conexão à internet e estão sujeitos à disponibilidade dos provedores.

1. Abrir no Windows

  1. Extraia o ZIP para uma pasta, por exemplo C:\WebGIS\ariquemes.
  2. Abra essa pasta no Explorador. Ela deve conter index.html, app.js, styles.css e a pasta dados.
  3. Clique na barra de endereço, digite cmd e pressione Enter.
  4. Execute o comando abaixo e mantenha a janela aberta.
py -m http.server 8000 --bind 127.0.0.1

Abra http://localhost:8000 no navegador. Se o comando py não existir, instale Python ou tente python no lugar de py. Não abra index.html por duplo clique: o navegador pode bloquear a leitura dos GeoJSON. Ctrl+C encerra o servidor.

2. Utilizar

  1. Escolha um dos três mapas base.
  2. Marque ou desmarque as camadas. Use o controle deslizante para ajustar a opacidade e “Ver” para enquadrar uma camada.
  3. Clique em um imóvel, trecho de rio ou limite para consultar seus atributos originais.
  4. Combine busca, condição, status e intervalo de área para filtrar os imóveis. Os filtros são cumulativos e afetam apenas essa camada.
  5. Clique em um resultado para localizá-lo. A lista exibe até 15 itens; o mapa e o download incluem todos.
  6. Use “Baixar imóveis filtrados” para obter um GeoJSON com os resultados.
  7. Escolha um rio e clique em “Enquadrar curso d’água”. Isso localiza seus trechos; não filtra a hidrografia.
  8. Use “Ver município” para retornar à extensão de Ariquemes. “Limpar filtros” restaura os imóveis.

3. Entender os arquivos

  • index.html: estrutura, títulos e controles da página.
  • styles.css: cores, tamanhos e disposição da interface.
  • app.js: carregamento das camadas, filtros, mapa e comandos.
  • dados/: os três arquivos geográficos originais. Nomes e campos devem corresponder aos usados em app.js.
  • LEIA-ME.html: estas instruções.

Edite HTML, CSS e JavaScript no VS Code ou Bloco de Notas. Salve os arquivos em UTF-8; não use Word.

4. Publicar no GitHub Pages

  1. Crie um repositório no GitHub. Antes de torná-lo público, confirme a autorização para divulgar os dados e suas licenças.
  2. Em Add file → Upload files, envie index.html, app.js, styles.css, LEIA-ME.html e a pasta dados. Não envie apenas o ZIP. index.html deve ficar na raiz do repositório.
  3. Em Settings → Pages, selecione Deploy from a branch, branch main e pasta /(root). Clique Save.
  4. Aguarde a conclusão da publicação e abra o endereço apresentado pelo GitHub.
  5. Para atualizar, envie o arquivo alterado no mesmo caminho, confirme o envio e aguarde nova publicação. Atualize o navegador com Ctrl+F5.

5. Dados e limites de interpretação

O limite municipal contém 1 feição, a hidrografia 313 e os imóveis rurais declarados 4.989. Os arquivos declaram CRS84, com coordenadas longitude/latitude. O mapa apresenta os dados originais; não faz validação cadastral, análise de sobreposições nem comprovação de domínio.

num_area é usado como valor de área informado no cadastro. A unidade não consta explicitamente nos arquivos anexados e deve ser confirmada na fonte. AT, PE e outros códigos de status são exibidos literalmente, sem interpretação não documentada. A hidrografia contém atributo DSVERSAO que menciona BHO de 2018; isso não garante atualização recente.

Registre fonte, data de obtenção, licença e metodologia antes de utilizar a aplicação como produto técnico. Não some áreas dos imóveis como se fossem área territorial exclusiva: polígonos declarados podem se sobrepor.

6. Resolver problemas

  • Nenhuma camada: use localhost e confira nomes da pasta dados e dos GeoJSON.
  • Mapa sem fundo: verifique internet e troque o mapa base.
  • Página sem estilo: confira styles.css no mesmo diretório de index.html.
  • Sem resultados: limpe os filtros e confira o intervalo de área.
  • Mapa lento: desative imóveis enquanto explora o fundo; reative para consultar. São quase cinco mil polígonos renderizados em canvas.
  • Impressão: aguarde os tiles carregarem. A impressão depende do navegador; não substitui uma composição cartográfica técnica com título, fonte e demais elementos.
